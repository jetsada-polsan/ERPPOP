# POPSTAR POS Go-Live UAT

เอกสารนี้เป็นเกณฑ์รับรอง POS ก่อนเปิดขายจริงแต่ละเครื่อง ผลการทดสอบต้องบันทึกต่อเครื่องและต่อสาขา

## เงื่อนไขก่อนเริ่ม

- ติดตั้ง POS รุ่นที่ ERP ประกาศล่าสุด
- ข้อมูลต้องอยู่ที่ `D:\POPSTAR-POS\data` และหน้า **สุขภาพ POS Local** แสดง SQLite ปกติ
- สินค้า ราคา โปรโมชั่น และแคชเชียร์ซิงก์ล่าสุดแล้ว
- ทดสอบด้วยสินค้าและกะทดสอบเท่านั้น ห้ามใช้ยอดขายจริงเพื่อทดสอบไฟดับหรือ Restore

## รายการรับรอง

| หัวข้อ | วิธีทดสอบ | ผ่านเมื่อ |
|---|---|---|
| Scanner | ยิง SKU 20 รายการและบาร์โค้ดสินค้า 5 รายการ | ถูกสินค้า ถูกจำนวน และไม่มีรายการซ้ำ |
| เครื่องชั่ง | สแกนสติกเกอร์ชั่งน้ำหนัก 5 ใบ | PLU, จำนวน/น้ำหนัก และราคาในบิลตรงสติกเกอร์ |
| ราคาและโปรโมชัน | ขายสินค้าปกติ, ราคาตามเวลา และโปรโมชัน | ยอดใน POS และ ERP ตรงกัน |
| เครื่องพิมพ์ | ออกบิลและพิมพ์ซ้ำ 2 ครั้ง | กระดาษ 58/80 มม. ถูกต้อง ไทยไม่เพี้ยน และยอดตรง |
| ลิ้นชักเงินสด | ชำระเงินสด 1 บิล | ลิ้นชักเปิดหลังชำระสำเร็จเท่านั้น |
| Offline | ตัดอินเทอร์เน็ต ขาย 3 บิล แล้วเปิดเน็ต | บิลอยู่คิวและส่งขึ้น ERP ครบ ไม่ซ้ำ |
| Restart | ระหว่างมีบิลรอส่ง ปิด POS แล้วเปิดใหม่ | คิวขายและกะยังอยู่ ส่งซ้ำด้วย id เดิม |
| Backup/Restore | สำรอง SQLite แล้ว Restore บนเครื่องทดสอบ | `integrity_check = ok` และห้าม Restore หากมีบิลค้าง |
| Update | อัปเดตจากรุ่นก่อนบนเครื่องทดสอบ | เปิดได้ ฐานที่ D: อยู่ครบ และคิวขายไม่หาย |
| ปิดกะ | เปิดกะ, ขาย, นำส่งเงิน, ปิดกะ | ยอดคาดการณ์ เงินนับ และรายงาน ERP ตรงกัน |

## เกณฑ์หยุดขายและแจ้ง IT

- `integrity_check` ไม่เป็น `ok`
- มีบิล `failed` หรือ `pending` แล้วส่งซ้ำไม่สำเร็จ
- ฐานข้อมูลอยู่ไดรฟ์ C: โดยไม่มีเหตุผลอนุมัติ
- ราคา/โปรโมชันที่ POS แสดงไม่ตรง ERP
- เครื่องพิมพ์หรือลิ้นชักทำงานผิดจังหวะ

ห้ามลบ `popstar-pos.db`, ห้าม Restore ระหว่างมีบิลค้าง และห้ามแก้ SQLite ด้วยโปรแกรมภายนอกในขณะที่ POS เปิดอยู่

## สิ่งที่ต้องระบุใน Hardware Profile

- รุ่นและการเชื่อมต่อเครื่องพิมพ์: USB, LAN หรือ Windows Printer
- รุ่นเครื่องสแกนและโหมด Keyboard หรือ Serial
- รุ่นเครื่องชั่งและรูปแบบบาร์โค้ด PLU
- รุ่นลิ้นชักและการต่อผ่านเครื่องพิมพ์
- ชื่อ Windows Printer และขนาดกระดาษ 58 หรือ 80 มม.

POS จะถือว่าเครื่องพร้อมเปิดขาย เมื่อทุกข้อผ่านและผู้ดูแลสาขารับรองผลในรอบ UAT นั้น
