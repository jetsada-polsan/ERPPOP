## คำสั่งเตรียมไว้สำหรับข้อมูลจริง

หลังเจ้าของอนุญาต deploy ตาม docs/OPERATIONS.md แล้ว ให้รันด้วยบัญชีผู้ดูแลบน server:

```bash
php artisan erp:uat-readiness --dry-run
php artisan erp:remove-test-price-tag --dry-run
```

คำสั่งแรกอ่านอย่างเดียวแม้ไม่ใส่ --dry-run ไม่แก้ข้อมูล ไม่เชื่อม MSSQL และจำกัดรายการตัวอย่างไม่เกิน 100 รายต่อส่วน
รายงานลูกค้านับเกณฑ์ชื่อ/เลขภาษี/ที่อยู่/ผู้ติดต่อที่ขาด ไม่อ้างว่าตรงกับนิยาม 291 รายเดิม
รายการยอด 150–200 เป็นเอกสารรอตรวจ ไม่ใช่รายการที่ปลอดภัยให้ลบ

เมื่อเจ้าของตรวจ dry-run ว่าเป็นป้าย TEST01 / TEST-Claude ที่ขอลบตรงตัวแล้ว จึงรัน:

```bash
php artisan erp:remove-test-price-tag
```

คำสั่งลบเฉพาะรหัสและชื่อที่ตรงทั้งคู่ ปฏิเสธถ้า TEST01 ถูกเปลี่ยนเป็นชื่ออื่น เก็บ audit และไม่แตะธุรกรรม/สต๊อก/GL
คำสั่งนี้ยังไม่ได้รันบน production ใน session นี้

## ข้อมูลที่ต้องได้รับจากเจ้าของ

- รายการผู้ใช้และสาขาประจำที่ถูกต้อง (ยกเว้นบัญชีส่วนกลางตามหน้าที่)
- บัญชีธนาคารจริงและผังบัญชีที่ต้องผูก
- รายการเอกสารทดสอบที่ยืนยันแล้ว ไม่ใช้ยอด 150–200 เป็นเกณฑ์ลบ
- ชื่อ/URL รายงาน BPlus ที่คาดว่าควรมีข้อมูล พร้อมวัน/สาขา
