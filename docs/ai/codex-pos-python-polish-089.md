# Codex: Python POS 0.8.9 — ปุ่มล้างช่องค้นหา + ภาษาหน้าจอตรงๆ + ยกเลิกบิลให้ง่าย + นับโปรหลายบรรทัดตาม ERP

Branch `claude/pos-python-settings-popup` ต่อจาก HEAD, commit เป็นขั้น push เมื่อผ่าน ห้าม deploy ห้ามแก้ PHP/`apps/pos-desktop/`
ทุกครั้งที่รัน Qt ตั้ง `QT_QPA_PLATFORM=offscreen` ห้ามสร้าง/เขียน PIN/password/token เรื่องเงินใช้ Decimal
เทสต์ที่อ่านไฟล์ต้องใช้ `encoding="utf-8"` และห้ามใช้ `time.tzset()` (รันบน Windows CI ไม่ได้)

เจ้าของทดสอบบนเครื่องร้านจริง (0.8.8) แล้วขอ:

1. **ช่องค้นหาสินค้าไม่มีปุ่ม × ล้าง** ต้องกดลบทีละตัว → ใส่ปุ่ม × ใหญ่ (กดง่ายบนทัชสกรีน) ที่ขวาของช่องค้นหา กดแล้วล้างข้อความ + กลับรายการสินค้าเดิม + focus ช่องค้นหาพร้อมยิงต่อ; หลังเลือกสินค้าจากผลค้นหาแล้วให้ล้างช่องค้นหาอัตโนมัติด้วย (เหมือนยิงบาร์โค้ด)
2. **ภาษาบนหน้าจอให้ตรงๆ ชาวบ้านเข้าใจ** ไล่ข้อความทุกปุ่ม/หัวข้อ/ข้อความเตือนที่เกี่ยวกับ PIN, เข้างาน, เปิดกะ, ปิดกะ, ล็อก, ยกเลิกบิล, คืนสินค้า, นำส่งเงิน เช่น
   - "ใส่รหัส PIN ของคุณ (4 หลัก)" / "หัวหน้าใส่รหัส PIN เพื่ออนุมัติ"
   - "เปิดกะ: นับเงินในลิ้นชักแล้วใส่ยอด" / "ปิดกะ: นับเงินในลิ้นชักทั้งหมด"
   - ข้อความ error ต้องบอกว่าต้องทำอะไรต่อ เช่น "PIN ไม่ถูก ลองใหม่" "ต้องเปิดกะก่อนจึงยกเลิกบิลได้"
   - ห้ามมีศัพท์ระบบ (token, sync, preview, payload, outbox, server_id) บนหน้าจอแคชเชียร์ (หน้าตั้งค่าเครื่องสำหรับผู้ดูแลยังใช้ได้)
3. **ยกเลิกบิล/คืนสินค้าให้ง่ายและชัด**: ปุ่ม "ยกเลิกบิล" มองเห็นชัดในหน้าบิลล่าสุด/ประวัติ → เลือกบิล → เหตุผล (ปุ่มเหตุผลสำเร็จรูป + พิมพ์เองได้) → หัวหน้าใส่ PIN บน pin-pad → ผลชัดเจน; ถ้ายังไม่เปิดกะ/ไม่ใช่บิลวันนี้/บิลยังไม่ส่ง ERP ให้บอกตรงๆ ว่าทำไมและต้องทำอะไร; ตรวจตาม ERP (`/api/pos/approver/verify`, `receipt/void`, `receipt/return`) ผู้อนุมัติ GM/BRANCH_MGR/IT_MGR
4. **โปรสินค้าเดียวกันหลายบรรทัด**: ERP เปลี่ยนเป็นรวม qty ทุกบรรทัดแล้ว (PR #6 `app/Services/Sales/PosPricingGuard.php` qtyPromotionDiscount aggregate) → แก้ `pos_python/promotions.py` ให้รวมเหมือนกัน (ราคาฐาน = ราคาตั้งของสินค้า) เทสต์ 2+2 ชิ้นกับโปรครบ 3 ได้ส่วนลด และโปร 8 แบบเดิมผ่าน
5. **จำนวนของแถมแสดง "1.00000000"** → แสดงแบบปกติ (1, 1.5, 1.250 กก.)
6. ตรวจว่าสินค้าขายเป็นกิโล (หน่วย กิโลกรัม/กก.) ที่ไม่มีคำว่า ชั่ง/ซั่ง เช่น 104011 "BB-B ก้าวหน้า (ถุง10kg.)" หน่วย กิโลกรัม — กติกาตอนนี้ตาม ERP is_scale (ชื่อ ชั่ง/ซั่ง หรือ PLU 800/801) จึงไม่ถามน้ำหนัก **ห้ามเปลี่ยนกติกาเอง** แค่จดลง task.md ให้เจ้าของตัดสินใจ
