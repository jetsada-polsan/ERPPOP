## คำตอบเจ้าของ (ถือเป็นกติกา)
1. DS = ขายเชื่อมี VAT, DSN = ขายเชื่อไม่มี VAT (เหมือน BPlus IB / IB-N) แยกตาม VAT ของ "สินค้า" ไม่ใช่ทั้งเล่ม
   BPlus ทำ 2 รอบ (เปิดใบขายเชื่อดึงใบจอง ลบสินค้าไม่มี VAT → บันทึก แล้วเปิด IB-N ดึงใบจองเดิม เหลือแต่สินค้าไม่มี VAT → บันทึก)
   ของเรา: เปิดใบจอง กดแปลงครั้งเดียว ระบบแยกรายการตาม is_vat ออกเป็น 2 บิล (DS + DSN) อัตโนมัติ ยอดสองบิลรวมต้องเท่าใบจองพอดี บิลไหนไม่มีรายการไม่ต้องสร้าง
2. การส่งของอิงใบจอง และพิมพ์ "ใบปะหน้า" ส่งของจากใบจอง (มีอยู่แล้วให้ตรวจ ถ้าไม่มีให้ทำ)
3. Confirm ใบจองถอยกลับได้ แต่ต้องผู้จัดการอนุมัติ (PIN/สิทธิ์ผู้จัดการ ใช้กลไกอนุมัติเดิม) + audit log; ถ้าออกใบขายแล้วต้องกลับรายการด้วย reversal เดิม ห้ามลบ
4. กันสต๊อกคงไว้ Confirm ได้ ถ้าสต๊อกในระบบไม่พอแต่ของจริงมี → ส่งคำขออนุมัติให้ผู้จัดการ (แจ้งเตือนในระบบ) อนุมัติแล้วจึงผ่าน
5. ส่งของปกติครบรอบเดียว ของที่ลูกค้าไม่รับ/ตีกลับ ให้ทำเป็นรับคืนอ้างอิงบิลขาย (ไม่ทำส่งบางส่วนซับซ้อน)
6. ยอด A/B (DS/DSN) ในรายงาน นับตามวันที่ใบจอง (จองเช้า ส่งบ่าย วันเดียวกัน) ห้ามนับซ้ำใบจองกับใบขาย
7. IT Admin เห็นต้นทุน/กำไรได้
8. ตรวจนับสต๊อก: ทำแบบ ERP มาตรฐาน — ปรับเฉพาะรายการที่นับ รายการที่ไม่ได้นับไม่ปรับ; โหมดปรับที่ไม่ได้นับเป็นศูนย์ ต้องผู้จัดการอนุมัติแบบ explicit เท่านั้น
9. รายงาน: ตัวหนังสือเล็กไป และแถบหัวกระดาษ (sticky header) บังข้อความ — แก้ทั้งหน้าจอและหน้าพิมพ์ให้อ่านง่าย (≥14px จอ, พิมพ์ไม่ถูกหัวทับ)
