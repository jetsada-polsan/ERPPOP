## 1. บทสรุปและที่มาของระบบ (Overview & Business Context)

ระบบ "ใบปะหน้า (ใบจองรายวัน)" พัฒนาขึ้นเพื่อทดแทนหน้าเว็บเดิมของระบบร้าน (`p_reserve_cover.php?date=...&route=...`) สำหรับให้พนักงานขับรถ/ขนส่งถือไปพร้อมกับสินค้า เพื่อ:
1. เช็ครายการสินค้าและยอดเงินที่จะต้องเก็บจากลูกค้าแต่ละรายตามสายส่ง (Route) ในแต่ละวัน
2. บันทึกค่าใช้จ่ายระหว่างทาง (เช่น ค่าน้ำมัน, ค่าจอดรถ, ค่าธรรมเนียม)
3. บันทึกข้อมูลการใช้รถ (เลขไมล์เริ่มต้น/สิ้นสุด, ปริมาณการเติมน้ำมัน, เวลาออกกะ)
4. นำใบปะหน้าพร้อมเงินสดและสลิปโอนส่งมอบให้ฝ่ายบัญชีตรวจสอบและตัดยอดหนี้

> [!IMPORTANT]
> **ระบบอ่านข้อมูลอย่างเดียว (Read-Only Safety)**:  
> หน้าจอนี้ไม่มีการแตะต้องหรือแก้ไขยอดเงิน สต็อก บัญชี หรือสิทธิ์ใดๆ ทั้งสิ้น และไม่มีการเขียนหรือแก้ไขข้อมูลลงในฐานข้อมูลจากหน้านี้

## 2. สิ่งที่พัฒนาและโครงสร้างระบบ (Architecture & Features)

### 2.1 หน้าจอและ Route ใหม่ (`bookings.cover-sheet`)
- **Route**: `GET /bookings/cover-sheet` (ชื่อ route: `bookings.cover-sheet`) ภายใต้กลุ่ม `bookings.`
- **เมนูบนระบบ**: เพิ่มรายการ "ใบปะหน้า (ขนส่ง)" ในเมนูหมวด `งานประจำวัน` (ขาย/เอกสาร) วางคู่กับ "ใบรวมจอง" และเพิ่มปุ่มทางลัดเชื่อมโยงไป-กลับระหว่างหน้า "ใบรวมจอง" และ "ใบปะหน้า (ขนส่ง)" พร้อมส่งค่าตัวกรองตามกัน
- **สิทธิ์การใช้งาน**: ใช้สิทธิ์เดิมของระบบงานขาย (`sales.manage`) ผ่าน `RoutePermissions` โดยไม่มีการสร้างสิทธิ์ใหม่

### 2.2 ตรรกะการดึงข้อมูลร่วมกับหน้าใบรวมจอง (Shared Query)
- สกัดฟังก์ชัน `BookingController::pendingBookingsQuery()` เพื่อเป็นจุดศูนย์กลางในการคิวรีใบจองสถานะ `pending` ที่ยังไม่ถูกยกเลิก (`status != 'cancelled'`, `status != 'voided'`)
- ทั้งหน้า **ใบรวมจอง (`bookings.summary`)** และหน้า **ใบปะหน้า (`bookings.cover-sheet`)** เรียกใช้ query เดียวกัน จึงการันตีว่าข้อมูลชุดเดียวกัน 100%
- แสดงยอดเงินรวมของใบจอง (`documents.total_amount`) ตามจริงจากฐานข้อมูล ไม่มีการคำนวณใหม่

### 2.3 ตัวกรองและการจดจำค่าในเบราว์เซอร์ (Filters & LocalStorage)
- **วันที่ (`date`)**: ค่าเริ่มต้นคือวันนี้ (`now()`)
- **สาขา (`branch_id`)**: กรองเฉพาะสาขาที่ผู้ใช้มีสิทธิ์ หากเป็นผู้ใช้ประจำสาขา ระบบจะล็อกให้เห็นเฉพาะสาขาตนเองเท่านั้น
- **สาย (Sale) (`sales_area_id`)**: มีตัวเลือกสายทั้งหมด และตัวเลือก `"ทุกสาย (พิมพ์ต่อเนื่องทุกสาย)"` สำหรับฝ่ายจัดของรอบเช้า
- **เลขที่ใบจอง (`booking_id`)**: ตัวเลือก `"ทั้งหมดในวันนั้น"` หรือเลือกเจาะจงเฉพาะใบจองใบใดใบหนึ่ง
- **บัญชีโอน (`bank_account_id`)**: ดึงรายการบัญชีธนาคารบริษัท (`bank_accounts`) ให้เลือก โดยระบบจะจำค่าบัญชีล่าสุดแยกตามแต่ละสายไว้ใน `localStorage`
- **ชื่อผู้ส่ง / ผู้ตรวจนับ / ผู้จัดทำบิล**: ช่องกรอกข้อความที่ระบบจะจดจำค่าล่าสุดของผู้ใช้ไว้ใน `localStorage` อัตโนมัติ (ไม่บันทึกลงฐานข้อมูล) พร้อมแสดงผลขึ้นบนช่องลงนามแบบ Real-time

### 2.4 โครงสร้างเอกสาร A4 (Paper Layout Matching Legacy System)
1. **หัวเอกสาร**:
   - ชื่อบริษัทจาก `AppSetting::company('name_th')`
   - ชื่อเอกสาร: `ใบจองสินค้า-<ชื่อสาย> / สรุปยอดส่งสินค้า (รายวัน)`
   - ข้อมูลระบุวันที่ (พ.ศ.), สาย, และเลขที่ใบจอง
2. **ตารางรายการ**:
   - ลำดับ, ชื่อลูกค้า, เลขที่บิล (เลขใบจอง), จำนวนเงิน (ทศนิยม 2 ตำแหน่ง)
   - ช่องว่างลายมือสำหรับ: **ยอดค้าง**, **รวม**, และ **หมายเหตุ**
   - แถวสรุปผลรวม: แสดงคำว่า `"รวม"` พร้อมผลรวมจำนวนเงินทศนิยม 2 ตำแหน่ง
3. **กล่องบันทึกเงินและค่าใช้จ่าย (ซ้าย)**:
   - "ส่งเงินผ่านการโอน/เคาน์เตอร์เซอร์วิส/ตู้ ATM"
   - ช่องกรอกลายมือ: ค่าธรรมเนียม, ค่าน้ำมัน, ค่าใช้จ่ายอื่นๆ (ค่าน้ำมัน, ค่าจอดรถ), ยอดลูกค้านำส่งโอนเข้าบัญชีบริษัท, และยอดเก็บเงินสดทั้งหมด
4. **กล่องข้อมูลรถและการใช้น้ำมัน (ขวา)**:
   - ทะเบียนรถ, เลขไมล์เริ่มต้น/สิ้นสุด, ระยะทางที่วิ่ง (กม.), ออกกะเวลา, เติมน้ำมันรอบเช้า, เติมน้ำมันเพิ่ม, และรวมเติมน้ำมัน
5. **ส่วนลายเซ็น**:
   - 4 ช่องลงนาม: ผู้ส่งสินค้า (ตัวบรรจง), ผู้ตรวจนับสินค้า, ผู้จัดทำบิล (แสดงชื่อที่พิมพ์ไว้เหนือเส้นเซ็น), และ ผู้ขนส่ง (ลงชื่อจริง)
6. **ท้ายเอกสาร**:
   - บัญชีโอน: `โอนเข้า: ธนาคาร <ชื่อธนาคาร> <ชื่อบัญชี> เลขที่บัญชี <เลขที่บัญชี>` (หากไม่เลือก เว้นช่องว่างให้เขียนมือ)

### 2.5 การพิมพ์ต่อเนื่องทุกสาย (Batch Printing)
- เมื่อเลือกตัวเลือก `"ทุกสาย"` ระบบจะจัดกลุ่มใบจองตามแต่ละสาย (`sales_area_id`) และสร้างชุดเอกสารแยกสายละ 1 ชุด
- แต่ละสายจะขึ้นหน้าใหม่เสมอด้วยคำสั่ง CSS `page-break-after: always; break-after: page;`
- กรณีสายใดมีรายการบิลยาวเกิน 1 หน้า หัวตารางจะปรากฏซ้ำทุกหน้า (`thead { display: table-header-group; }`) และแถวตารางจะไม่ขาดครึ่งแผ่น (`tr { break-inside: avoid; }`)
- ซ่อนแถบเมนูข้าง แถบบน และปุ่มตัวกรองทั้งหมดตอนพิมพ์ ด้วย `.no-print` และกฎพิมพ์หลักจาก PR #45

### 2.6 ส่งออก Excel (CSV UTF-8 พร้อม BOM)
- มีปุ่ม **Export Excel** รองรับพารามิเตอร์ `?export=csv`
- ส่งออกไฟล์ CSV พร้อมไบต์ **UTF-8 BOM (`\xEF\xBB\xBF`)** ที่หัวไฟล์ เพื่อให้โปรแกรม Microsoft Excel ทั้งบน Windows และ Mac เปิดอ่านภาษาไทยได้ถูกต้องโดยไม่เป็นภาษาต่างดาว
- มีคอลัมน์: `ลำดับ`, `ชื่อลูกค้า`, `เลขที่บิล`, `จำนวนเงิน` พร้อมแถวสรุปผลรวมที่ด้านล่างสุด
