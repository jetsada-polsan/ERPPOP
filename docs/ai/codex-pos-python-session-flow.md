# Codex: Python POS — เปิด/ปิดโปรแกรม, เข้างาน/ออกงาน, โลโก้ ให้เหมือน JET POS Vue (0.8.5)

Branch `claude/pos-python-settings-popup` ต่อจาก HEAD, commit เป็นขั้น push เมื่อผ่าน ห้าม deploy ห้ามแก้ `apps/pos-desktop/` หรือ PHP
ห้ามสร้าง/เขียน PIN/password/token ทุกครั้งที่รัน Qt ตั้ง `QT_QPA_PLATFORM=offscreen` (เคยเด้งหน้าต่างขึ้นจอ Mac เจ้าของ)

เจ้าของจะเริ่มขายจริงด้วยตัวนี้ ต้องใช้ง่ายสำหรับแคชเชียร์บนทัชสกรีน 1024x768

## ต้นแบบ Vue (`apps/pos-desktop/src/App.vue`)
- โลโก้ `apps/pos-desktop/src/assets/mpm-logo.jpg` บนแถบบน (`.brand-logo` บรรทัด ~1048), ไอคอนแอป `src-tauri/icons/*`
- ปุ่ม เข้าสู่ระบบ/ออกจากระบบ (`logoutCashier`, บรรทัด ~1057), modal `cashier`, `shift`, `closeShift`, `closeApp` (~1229)
- เปิดเครื่องต้องล็อกเสมอ (brief เดิมข้อ 7)

## ต้องทำ
1. **โลโก้**: ใส่ mpm-logo บนแถบบน, บนหน้าล็อก/ใส่ PIN, บนหน้าตั้งค่าครั้งแรก, ใน Z/ใบเสร็จถ้าเทมเพลตมีช่อง logo; ไอคอนหน้าต่าง (`setWindowIcon`) + ไอคอนไฟล์ .exe/shortcut ของ PyInstaller/Inno Setup (แปลง png → .ico ตอน build ใน workflow `.github/workflows/pos-python-windows-uat.yml` หรือ commit .ico ที่สร้างจาก icons เดิม)
   ชื่อบนหน้าต่าง/installer เปลี่ยนจาก "PopCentral POS" เป็น **"JET POS"** (คงชื่อไฟล์ setup `PopCentral-POS-UAT-*-setup.exe` ไว้ เพราะหน้าดาวน์โหลด ERP หาไฟล์ด้วยชื่อนี้)
2. **เปิดโปรแกรม**: splash/หน้าล็อกเต็มจอมีโลโก้ → ปุ่มใหญ่ "เข้างาน" → PIN pad → ถ้ายังไม่มีกะ เด้ง "เปิดกะ" ต่อทันที (เงินทอนเริ่มต้น numpad) → เข้าหน้าขาย; ถ้ามีกะอยู่แล้วเข้าหน้าขายเลย
3. **แถบบน**: ปุ่มชัด 3 ปุ่ม "🔒 ล็อก/สลับคนขาย" (กลับหน้าล็อก กะยังเปิด ตะกร้าคงอยู่) | "ออกงาน" (ปิดกะ: นับเงิน → ยืนยัน → พิมพ์ Z → กลับหน้าล็อก) | "⏻ ปิดโปรแกรม"
   ชื่อคนขายปัจจุบันแสดงตลอด
4. **ปิดโปรแกรม** (ปุ่ม X ของหน้าต่าง, Alt+F4, ปุ่มปิดโปรแกรม): popup ใหม่แบบ Vue `closeApp` — ปุ่มใหญ่ "กลับไปขายต่อ" (ค่าเริ่มต้น, Esc), "ล็อกหน้าจอ", "ปิดโปรแกรม" (สีแดง อยู่ห่างจากปุ่มอื่น ต้องกดยืนยันอีกชั้นถ้ามีตะกร้าค้างหรือบิลรอส่ง)
   **ตะกร้าค้างต้องไม่หายเมื่อปิดแล้วเปิดใหม่** (เคยหายจริง 9 ชิ้น ฿1,430 ตอนอัปเดต) — ทดสอบ restart แล้วตะกร้ากลับมา
   ย่อ/ปิดหน้าต่างแล้วห้ามข้ามหน้าล็อกได้
5. **กล่องข้อความ Windows ที่เหลือ** (`QMessageBox`, `QInputDialog` ทุกที่ใน ui.py) → popup แบบ TouchDialog เดียวกัน เช่น "ไม่พบสินค้าสำหรับ PLU", "ล้างรายการทั้งบิลใช่ไหม", "ยังไม่มีบิลพัก", "น้ำหนักไม่ถูกต้อง"
   เพิ่มเทสต์ที่ตรวจว่า ui.py ไม่มี `QMessageBox.` / `QInputDialog.` เหลือ
6. ภาพ offscreen 1024x768: หน้าล็อก, PIN, เปิดกะ, หน้าขาย(แถบบนใหม่+โลโก้), popup ปิดโปรแกรม, ออกงาน ใน `docs/ai/pos-python-shots/session/`
