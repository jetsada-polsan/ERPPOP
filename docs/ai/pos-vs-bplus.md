## ยังขาด

| ลำดับ | งาน | หลังบ้านมีแล้วไหม | ทำบนเครื่อง POS |

| 1 | ยกเลิกบิล (บิลวันนี้ กะที่เปิดอยู่) | มี `/receipt/void` | ปุ่มในประวัติการขาย + PIN หัวหน้า + เหตุผล |

| 8 | เปิดลิ้นชักเงิน / จอลูกค้า | มีค่าใน hardware profile | ต้องทดสอบกับเครื่องจริงที่ B001 |

## ต้องแก้ฝั่งเซิร์ฟเวอร์ก่อนทำข้อ 1-2

`voidReceipt` และ `returnReceipt` ตรวจสิทธิ์ `pos.void` จาก user ที่ผูกกับ token เครื่อง
ไม่ใช่หัวหน้าที่ยืนยัน PIN ถ้า user ของเครื่องไม่มีสิทธิ์ ปุ่มบนเครื่องจะใช้ไม่ได้เลย
ถ้าให้สิทธิ์ user ของเครื่องแทน แคชเชียร์ทุกคนจะยกเลิกบิลได้โดยไม่มีใครอนุมัติ
ต้องให้ API รับ `approver_id` + PIN ตรวจด้วยกฎเดียวกับ `verifyApprover` และบันทึกชื่อหัวหน้าใน audit log

## ยังไม่ได้ทดสอบ

- popup น้ำหนัก: ผ่าน `vue-tsc` แต่รัน vitest บนเครื่องนี้ไม่ได้ (rollup native module) และยังไม่ได้ลองบนเครื่องจริง
- ฟิลด์ `is_scale` มาจากสินค้าที่มีบาร์โค้ด SCALE_PLU หรือชื่อสินค้าบอกว่าเป็นสินค้าชั่ง ถ้าสินค้าชั่งตัวไหนไม่เด้ง ให้ตรวจสองอย่างนี้
