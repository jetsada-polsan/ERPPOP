# Codex รอบต่อ: หน้าปิดกะ Python POS ซ้ำซ้อน/ซ้อนกัน — ออกแบบใหม่เป็นหน้าเดียว (ต่อจากงาน shift-float)

เจ้าของเปิดดูบนเครื่องร้านจริง (0.8.5, จอ 1024x768) แล้วเจอ:
- กด "นำส่งเงินระหว่างกะ" ในหน้าปิดกะ → popup "รายการเงินสด" เด้ง **ซ้อนทับ** popup ปิดกะ ทั้งสองอันมี header ซ้ำกัน ปุ่ม × สองอัน ดูสับสน
- popup ปิดกะ **สูงเกินจอ** ปุ่ม "ปิดกะขาย" ถูกตัดล่าง numpad โดนบัง
- เงินสดที่ควรมีแสดงก่อนนับ (ผิดหลัก blind count)
- "นำส่งเงินระหว่างกะ" กับ "เงินนำส่งตอนปิดกะ" ดูเป็นเรื่องเดียวกัน คนงง

## ออกแบบใหม่ (ห้าม popup ซ้อน popup ทั้งแอป)
1. **ปิดกะ = หน้าเต็มจอเดียวแบบขั้นตอน (wizard) ไม่ใช่ popup** แถบขั้นบนสุด: ① นับเงิน → ② ตรวจยอด → ③ แยกเงินทอน/นำส่ง → ④ ยืนยัน+พิมพ์ Z
   - ① ซ้าย: ตารางนับแบงก์/เหรียญ (จำนวน × ชนิด = ยอด) ขวา: numpad ใหญ่ ช่องที่เลือกอยู่ไฮไลต์ ยอดรวมตัวใหญ่ด้านล่าง — **ไม่แสดง expected**
   - ② หลังกด "ถัดไป" → preview จาก ERP: ควรมี / นับได้ / ขาด-เกิน (สี) + รายการนำส่งระหว่างกะที่บันทึกไปแล้ว (อ่านอย่างเดียว)
   - ③ เงินทอนเก็บในลิ้นชัก (ค่าเริ่ม default_float, แก้ได้) → เงินนำส่ง = ERP คำนวณ แสดงตัวใหญ่ + ช่องเลขซอง
   - ④ สรุปทั้งหมด + ปุ่ม "ยืนยันปิดกะและพิมพ์ใบปิดกะ" ปุ่ม "ย้อนกลับ" ทุกขั้น
   - ทุกขั้นพอดี 1024x768 ไม่มี scroll ไม่มีปุ่มโดนตัด
2. **นำส่งเงินระหว่างกะ ย้ายออกจากหน้าปิดกะ** ไปเป็นปุ่มของมันเองบนแถบบน/เมนู "เงินสด" (มีอยู่แล้ว "เงินสดระหว่างกะ") หน้าเดียว: จำนวน (numpad) + เลขซอง + เหตุผล → ยืนยัน
   ใช้ชื่อให้ไม่ชนกัน: "นำส่งเงินระหว่างกะ" (ระหว่างวัน) vs "เงินนำส่งปิดกะ" (ตอนจบ)
3. ตรวจ popup ทุกตัวในแอป: เปิดจาก popup อื่นต้อง **แทนที่** (ปิดตัวเดิม/เปลี่ยนหน้าใน dialog เดียว) ห้ามซ้อน — เพิ่มเทสต์ที่จับว่าไม่มี TouchDialog เปิดซ้อนกัน
4. ภาพ offscreen 1024x768 ทุกขั้นของ wizard + หน้านำส่งระหว่างกะ ใน `docs/ai/pos-python-shots/shift-float/`
