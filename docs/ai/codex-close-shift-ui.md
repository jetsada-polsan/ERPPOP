3. ขั้น 1 ช่องกรอกจำนวนในตารางนับเงินล้นทับแถว → ความสูงแถวต้องพอดีช่องกรอก ตารางทั้ง 11 แถวเห็นครบหรือเลื่อนในตารางได้
