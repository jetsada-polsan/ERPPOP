# Codex เพิ่มเติม 0.8.9: flow ยกเลิกบิลตามที่เจ้าของกำหนด
ยกเลิกบิล = ดึงบิลมา (ค้นเลขบิล/เลือกจากบิลล่าสุด) → เลือกบิล → เลือกผู้อนุมัติจากรายชื่อ (เฉพาะ GM / ผู้จัดการสาขา / IT admin ตาม ERP) → ผู้อนุมัติใส่ PIN บน pin-pad
**PIN ต้องไม่แสดงบนจอเด็ดขาด** (แสดงเป็นจุด ●), ห้าม log/เก็บ PIN ในไฟล์ ฐานข้อมูล หรือข้อความ error; ล้างค่าทันทีหลังส่ง; ใช้กับทุกจุดที่ใส่ PIN (เข้างาน, อนุมัติส่วนลด, ยกเลิก/คืน)
เทสต์: PIN ไม่ปรากฏใน widget text/log, รายชื่อผู้อนุมัติไม่มีแคชเชียร์ธรรมดา, flow ครบ
