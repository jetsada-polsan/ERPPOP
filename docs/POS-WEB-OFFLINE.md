# Web POS ขายออฟไลน์ (PWA)

Host เป็นระบบหลัก แอปที่ติดตั้งในเครื่องเป็นเครื่องขายสำรองตอนเน็ตหรือ Host ล่ม ไม่ต้องลงโปรแกรมหรือฐานข้อมูลแยก

## ส่วนประกอบ

| ส่วน | ไฟล์ | หน้าที่ |
|---|---|---|
| Service Worker | `public/pos-sw.js` (cache `popstar-pos-v3`) | เก็บหน้า POS, JS/CSS (`/build/`, `/vendor/`), `pos-offline.js` และ html5-qrcode ให้เปิดได้ตอนไม่มีเน็ต |
| IndexedDB | `public/pos-offline.js` (`popstar-pos-offline`) | สินค้า+ราคา+บาร์โค้ด สูงสุด 20,000 รายการ, คิวบิลออฟไลน์, meta |
| localStorage | `popstar_pos_shift_<user>`, `popstar_pos_promotions_<user>`, `popstar_pos_last_online_<user>` | กะล่าสุด, โปรโมชันล่าสุด, เวลาออนไลน์ล่าสุด |
| Server | `PosOfflineSaleController`, ตาราง `pos_offline_sales` | รับคิวบิล, กันบิลซ้ำ, ติดป้ายต้องตรวจสอบ |

ไม่เก็บรหัสผ่านในเครื่อง ตัวตนผู้ขายมาจาก session เว็บที่ล็อกอินออนไลน์ล่าสุด ขายออฟไลน์ได้ภายใน 15 วันนับจากออนไลน์ครั้งล่าสุดบนเครื่องนั้น (ต่ออายุเองทุกครั้งที่ต่อ Host ได้)

## การทำงาน

- **ออนไลน์**: ขายเข้า Host ตามปกติ ทุกบิลแนบ `X-Offline-Uuid` อัปเดตสินค้าลงเครื่องตอนเปิดแอป, เน็ตกลับมา และทุก 10 นาที
  แถบบนแสดง "สินค้าอัปเดต HH:MM" เป็นสีเหลืองถ้าเก่าเกิน 30 นาที
- **ตรวจ Host**: `GET /pos/ping` ทุก 20 วินาที (ไม่ผ่าน cache) คืน CSRF token ใหม่ด้วย
- **Host ล่ม** (เน็ตหลุด, fetch ล้ม, 502/503/504): สลับไปขายในเครื่อง ค้นสินค้า/บาร์โค้ด/SKU จาก IndexedDB
  บิลเข้าคิวพร้อมเวลาขายจริงและราคาตอนขาย ใบเสร็จแสดงเลข `OFF-xxxxxxxx`
- **Host กลับมา**: ส่งคิวที่ `POST /pos/offline-sales/sync` ครั้งละ 50 บิล ใช้ `offline_uuid` กันบิลซ้ำ
  บิลลงผ่าน `PosController::checkout` ตัวเดิม (ราคา/สต๊อก/บัญชีไม่มีทางลัด) หมายเหตุบิลมี "ขายออฟไลน์ dd/mm/yyyy HH:MM"
- **รับไม่ได้** (ราคาไม่ตรง, กะปิดแล้ว, สินค้าถูกปิด ฯลฯ): บิลไม่หาย เก็บเป็น `needs_review` ที่หน้า `/pos/offline-sales`
  ผู้จัดการ (สิทธิ์ `pos.void`) กด "ส่งใหม่" (ระบุกะใหม่ได้ ลงในชื่อคนขายจริง) หรือ "ปิดรายการ" พร้อมบันทึกเหตุผล

## กันพลาด

- ปุ่มสถานะบนแถบบนเปิด **เช็กลิสต์ความพร้อมขายออฟไลน์**
- ถ้าเครื่องยังไม่มีสินค้าในเครื่อง มีแถบเหลืองเตือน
- ตอนออฟไลน์ กดออกจากระบบไม่ได้
- ปิดกะไม่ได้ถ้ายังมีบิลรอส่ง
- ออฟไลน์ใช้บัตรส่วนลด/แลกแต้มไม่ได้, ต้องเปิดกะตอนออนไลน์ก่อน

## ข้อจำกัด

- เลขที่บิลจริงออกตามลำดับที่ส่งขึ้น Host ไม่ใช่ลำดับที่ขาย; วันที่เอกสารคือวันที่ส่งขึ้น เวลาขายจริงอยู่ในหมายเหตุและ `pos_offline_sales.sold_at`
- สต็อกตัดตอนบิลส่งขึ้น Host; หลายเครื่องขายออฟไลน์พร้อมกันจะไม่เห็นสต็อกของกันและกัน
- ราคาแพ็ค (บาร์โค้ดที่มี unit_factor แต่ไม่มีราคาบาร์โค้ด) คิดเป็นราคาฐาน × factor ถ้าไม่ตรงตารางราคาจะติด "ต้องตรวจสอบ"
- ล้างข้อมูลเว็บไซต์/ถอนแอป = คิวบิลที่ยังไม่ส่งหาย ให้ส่งคิวให้หมดก่อนทุกครั้ง

## ใช้งาน

ติดตั้งเป็นแอป (Chrome/Edge → ติดตั้ง) แล้วล็อกอินและเปิดกะออนไลน์บนเครื่องนั้นอย่างน้อยหนึ่งครั้ง รอให้เช็กลิสต์เป็นสีเขียว

## UAT ที่ต้องทำบนเครื่องจริง

1. ออนไลน์ → เปิดกะ → เช็กลิสต์เขียวครบ
2. ปิด Wi-Fi → ยิงบาร์โค้ด/ค้นชื่อ → คิดเงินสด → ได้ใบเสร็จ `OFF-...` และ "รอส่ง 1"
3. ปิดแอปแล้วเปิดใหม่ตอนยังออฟไลน์ → หน้า POS เปิดได้และคิวยังอยู่
4. เปิด Wi-Fi → ภายใน 20 วินาทีบิลส่งขึ้นเอง → เห็นบิลใน ERP พร้อมหมายเหตุ "ขายออฟไลน์"
5. แก้ราคาสินค้าบน Host ระหว่างออฟไลน์ → บิลขึ้นที่ `/pos/offline-sales` เป็น "ต้องตรวจสอบ"
6. ดึงสาย LAN ระหว่างกดคิดเงิน → ต้องไม่เกิดบิลซ้ำหลังเน็ตกลับมา
