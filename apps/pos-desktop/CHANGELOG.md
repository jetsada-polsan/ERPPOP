# POPSTAR POS — บันทึกการเปลี่ยนแปลง

## 1.5.0

**รองรับบาร์โค้ด 4 ประเภท**

เครื่องรู้แล้วว่าบาร์โค้ดแต่ละตัวเป็นประเภทไหน แทนที่จะเดาจากรูปร่างของตัวเลข

| ประเภท | เครื่องทำอะไร |
|---|---|
| EAN-13 มาตรฐาน | ใช้ค่าที่ sync มาตรง ๆ ตรวจ check digit แล้วเตือนถ้าไม่ตรง **ไม่แก้เลขให้เอง** |
| รหัส 13 หลักภายใน | ขายได้ตามค่าดิบ แม้ check digit ไม่ตรงสูตร |
| บาร์โค้ดเครื่องชั่ง | ถอด PLU กับราคาแล้วผูกกับสินค้าที่ลงทะเบียน PLU ไว้ |
| กำหนดเอง / ของเก่า | ขายได้ทุกรูปแบบ ไม่บังคับ |

**ที่แก้เพิ่ม**

- บิลที่ขายตอนออฟไลน์เก็บบาร์โค้ดที่สแกนจริงและประเภทไว้ด้วย เซิร์ฟเวอร์ตรวจซ้ำตอน sync ว่าบาร์โค้ดยังเป็นของสินค้าตัวเดิม ถ้าแคตตาล็อกในเครื่องเก่าจนบาร์โค้ดย้ายไปสินค้าอื่นแล้ว บิลจะถูกปฏิเสธพร้อมบอกให้ sync ใหม่ แทนที่จะตัดสต๊อกผิดตัวเงียบ ๆ
- แก้ PLU บนป้ายเครื่องชั่งแล้วสวมเป็นสินค้าอื่นไม่ได้ check digit จะไม่ตรงทันที
- สินค้านำเข้าที่บาร์โค้ดขึ้นต้น 800/801 และลงทะเบียนไว้แล้ว อ่านเป็นสินค้าปกติ ไม่ถูกตีความเป็นป้ายชั่ง

**การอัปเดตฐานข้อมูลในเครื่อง**

เพิ่มตารางบาร์โค้ดใหม่อย่างเดียว **บิลที่ยังส่งไม่ขึ้น ประวัติขาย บิลพัก และคิว sync อยู่ครบเหมือนเดิม** มีเทสต์ยืนยันข้อนี้โดยเฉพาะ

**หลังอัปเดตต้อง sync แคตตาล็อกใหม่หนึ่งรอบ** เพื่อให้เครื่องได้ประเภทบาร์โค้ดมา ระหว่างที่ยังไม่ sync บาร์โค้ดทุกตัวจะถูกถือเป็นแบบ "กำหนดเอง" ซึ่งยังขายได้ตามปกติ
